## Image Specifications

**Format**: JPG (JPEG recommended)
**Max File Size**: 2MB per image
**Color Space**: sRGB
**Quality**: 80-85%

## Quick Setup with Placeholders

If you want to see the website working immediately while you prepare your images:

1. **Create placeholder images** using any image editing tool
2. **Name them according to the list above**
3. **Add your real photographs gradually**

The website will work with any images, but use your best wildlife photography for the final version.

## Image Optimization

Before adding images:

1. **Resize to recommended dimensions**
2. **Compress to reduce file size**
   - Use tools: TinyPNG, Squoosh, Photoshop "Save for Web"
3. **Sharpen for web** (slight sharpening for screen display)
4. **Convert to sRGB** color space
5. **Save as JPG** with 80-85% quality

## Testing Images

After adding images:

```bash
npm run dev
```

Visit each page to verify:
- Images load correctly
- No distortion or stretching
- Proper aspect ratios maintained
- Fast loading times
- Mobile display looks good

## File Naming Rules

✅ **Good naming:**
- `hero.jpg`
- `portfolio-1.jpg`
- `species-elephant-1.jpg`

❌ **Bad naming:**
- `Hero.JPG` (uppercase extension)
- `Portfolio 1.jpg` (space in name)
- `IMG_1234.jpg` (non-descriptive)
