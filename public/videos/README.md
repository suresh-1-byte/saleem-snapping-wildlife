# Video Directory

## Camera Animation Video

Place your camera animation video here with the name: `camera-animation.mp4`

### Video Requirements:
- **Format**: MP4 (H.264) or WebM
- **Name**: `camera-animation.mp4` or `camera-animation.webm`
- **Duration**: 10-30 seconds recommended
- **Resolution**: 1920x1080 or higher
- **Aspect Ratio**: 16:9 recommended

### How It Works:
The video will be controlled by scroll:
- Scroll down = video plays forward
- Scroll up = video rewinds
- Stop scrolling = video freezes
- Section is pinned for 300% viewport height

### If No Video File:
The component will still work but show a black screen. Add your video file to enable the scroll-controlled playback.

### Tips:
- Keep file size under 20MB for fast loading
- Use compressed/optimized video
- Consider multiple formats (MP4 + WebM) for browser compatibility
